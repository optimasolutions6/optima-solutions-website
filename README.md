# Optima Solutions Premium — Versión 4 Final

Sitio corporativo multipágina listo para GitHub y Vercel.

## Incluye
- Diseño premium responsive
- Home corporativo ampliado
- Mapa visual de cobertura y consulta por ZIP
- Formulario de leads mediante Vercel Serverless Function
- Eventos de llamadas, cobertura y formularios para Google Tag Manager
- FAQ, Privacidad, Términos y Aviso Legal
- SEO técnico, Schema.org, sitemap y robots.txt
- Imágenes WebP optimizadas
- Favicon propio
- Animaciones y contadores basados en datos verificables

## Configurar el formulario en Vercel
Agrega estas variables de entorno:
- `RESEND_API_KEY`
- `LEADS_TO_EMAIL`
- `LEADS_FROM_EMAIL` (opcional; usa un remitente verificado en Resend)

Sin estas variables, el formulario mostrará el teléfono como alternativa.

## Publicación
Sube todos los archivos y carpetas a la raíz del repositorio. Vercel detectará el proyecto como `Other` sin build command.

## Transparencia
No se incluyen testimonios, ventas, clientes o métricas inventadas. Los textos legales deben revisarse conforme a las jurisdicciones aplicables.
